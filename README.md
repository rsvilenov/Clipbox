Clipbox is a visual clipboard manager for Windows with preview cards for the clipboard items, search, Windows Shell integration, cloud support, encryption, advanced settings, localization, Windows service and error collecting and reporting agent, .
The UI is written in WPF, completely manually (no design framework). The backend mostly consists of WinAPI integration and orchestration services.

The project is abandoned. There is a recent project of the same name in Windows Store, which has nothing to do with this one here, and, frankly, looks vibe coded.
